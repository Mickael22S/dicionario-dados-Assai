# Dicionário de Dados - E-commerce e Gestão de Pedidos (Assaí Atacadista)

Este repositório contém a documentação completa, modelagem de banco de dados e interface web interativa do **Dicionário de Dados** desenvolvido para o sistema de e-commerce e gestão de pedidos do **Assaí Atacadista**, estruturado no modelo de atacarejo.

##  Sobre o Projeto

O sistema foi modelado para atender tanto consumidores finais (**PF**) quanto pequenos comerciantes (**PJ**), oferecendo regras de preços diferenciados. O projeto foca em:
- **Controle rigoroso de estoque** distribuído por loja/centro de distribuição.
- **Precificação automatizada** de atacado com base no volume de compra.
- **Imutabilidade do histórico de pedidos** para fins fiscais e de auditoria.
- **Conformidade regulatória** total com a LGPD (Lei Geral de Proteção de Dados), o CDC (Código de Defesa do Consumidor) e normas fiscais vigentes.

##  Tecnologias Utilizadas

- **Banco de Dados:** MySQL (InnoDB, charset `utf8`)
- **Documentação e Interface:** HTML5, CSS3, JavaScript (com suporte a modo claro/escuro e Diagrama Entidade-Relacionamento interativo)
